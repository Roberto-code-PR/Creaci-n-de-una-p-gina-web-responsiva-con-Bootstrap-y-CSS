DESCRIPCION DE LA TAREA:

Este proyecto consiste en el desarrollo de una pagina web responsiva 
utilizando HTML5, CSS personalizado y el framework Bootstrap 5.

Se implemento una estructura semantica con navbar, seccion principal,
sistema de grillas (grid) con 3 columnas informativas y footer. 
Se utilizo un selector por ID y una clase personalizada para aplicar
estilos propios sobre Bootstrap, logrando un diseno adaptable a 
dispositivos moviles y de escritorio.

Archivos incluidos en el ZIP:

- index.html
- style.css
- bootstrap.css
- bootstrap.bundle.min.js
- README.txt
